# Rifanss Core

استبدل الموقع الحالي بالكامل بالمشروع الموجود في مستودع GitHub التالي:

https://github.com/poodcasts77-ops/Rifanss.git

استخدم المستودع كمصدر كامل ووحيد للموقع الجديد، واستبدل جميع ملفات وأكواد وتصميم ومكونات الموقع الحالي بمحتويات هذا المستودع.

أمر الاستنساخ عبر واجهة سطر الأوامر:

gh repo clone poodcasts77-ops/Rifanss

المطلوب:

استبدال الموقع الحالي بالكامل، وليس دمج المشروع الجديد معه.

عدم الاحتفاظ بأي ملفات أو مكونات أو صفحات أو أكواد من النسخة الحالية إلا إذا كانت مطلوبة لتشغيل المشروع الموجود في المستودع.

اعتماد جميع الملفات والمجلدات والإعدادات الموجودة في المستودع كما هي.

تثبيت جميع الحزم والاعتماديات المطلوبة للمشروع.

التأكد من إعداد متغيرات البيئة المطلوبة دون كشف أي مفاتيح أو بيانات سرية.

تشغيل المشروع والتحقق من عدم وجود أخطاء في البناء أو التشغيل.

التأكد من عمل جميع الصفحات والمسارات والمكونات والوظائف الموجودة في المستودع.

جعل المشروع الموجود في المستودع هو النسخة الأساسية والنهائية للموقع داخل Lovable.

مهم جدًا:
لا تقم بإعادة تصميم الموقع أو تعديل واجهاته أو تغيير محتواه أثناء عملية الاستبدال. المطلوب نقل واعتماد المشروع الموجود في المستودع بالكامل كما هو، مع إجراء التعديلات التقنية الضرورية فقط لضمان تشغيله بشكل صحيح داخل بيئة Lovable.
