# تعديلات صفحة بيانات العميل

النطاق: تبويب «بياناتي» في لوحة العميل فقط. لا تغيير في الخطوط أو أحجام الحقول أو الألوان العامة أو الوظائف أو قاعدة البيانات.

## 1. محاذاة الحقول لليمين
- كل input / textarea / select داخل الصفحة تبدأ قيمته من اليمين، بما فيها البريد والجوال والأرقام والتواريخ والبحث.
- تغيير المحاذاة فقط (text-align: right مع direction RTL للعرض) دون لمس الحجم أو الحشو أو الارتفاع أو الحواف.

## 2 و3. حذف «اكتمال الملف» وزر «إكمال»
- حذف الدائرة والنسبة وعبارة «اكتمال الملف» وزر «إكمال» بالكامل مع حاويتها، وحذف حساب النسبة المرتبط بها.
- نافذة إكمال الملف نفسها تبقى كما هي (تُفتح من أماكن أخرى إن وُجدت) — لا تُحذف وظيفتها.

## 4 إلى 6. بطاقة العميل البنفسجية
- تصغير البطاقة بنحو 50%: حشو أقل، حواف متناسقة مع الموقع، إزالة الحلقات الزخرفية في الخلفية وعبارة «مرحباً،».
- المحتوى فقط: اسم العميل (العنصر الأوضح) وتحته «رقم العميل: …» بحجم أصغر.
- إزالة القيم الثابتة الاحتياطية (اسم «ماجد عامر السفياني» ورقم «RF-20260331-7247» المكتوبين في الكود) وعرض البيانات الفعلية فقط؛ إن لم يتوفر أحدها يُعرض «—».
- الإبقاء على نفس اللون البنفسجي والذهبي.

## التحقق
- فحص الصفحة بعرض جوال 390px بحساب عميل: لا فراغات، البطاقة مضغوطة، الحقول محاذاة لليمين، ولا تغيّر في أحجام بقية العناصر.

## تفاصيل تقنية
- الملف: src/components/rifans/CustomerDashboard.tsx (قسم activeTab === 'profile').
- المحاذاة عبر قاعدة CSS مقيدة بحاوية التبويب (مثلاً `[data-profile-tab] input, textarea, select { text-align: right; direction: rtl; }`) حتى لا تتأثر صفحات أخرى.
