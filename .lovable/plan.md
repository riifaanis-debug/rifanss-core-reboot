# نظام إشعارات البريد الإلكتروني لرحلة العميل والطلب

البريد قناة إضافية بجانب الإشعارات داخل الموقع. لا تغيير على OTP أو الدخول أو المفتاح أو نصوص المستندات أو الأتعاب أو التصميم.

## 1. كيف يعمل
- بعد نجاح كل عملية وحفظها (وفي نفس النقاط التي تُنشأ فيها الإشعارات الداخلية الآن) يطلب الموقع من الخادم «أرسل بريد الحدث X للعنصر Y» فقط.
- الخادم يتحقق من هوية المستدعي وصلاحيته على العنصر، ثم **يقرأ البيانات من القاعدة بنفسه** (الاسم، البريد، رقم الطلب، المبلغ المحفوظ في الفاتورة...) — لا يُقبل نص أو مستلم من المتصفح.
- بريد العميل = البريد المسجل في حسابه؛ بريد المسؤول = ADMIN_EMAIL الحالي.
- المرسل: «ريفانس المالية <no-reply@mail.rifanss.com>» عبر Resend الموجود.

## 2. منع التكرار (إلزامي)
- جدول سجل جديد لإرسالات البريد بمفتاح فريد (الحدث + معرّف العنصر). يُحجز السجل قبل الإرسال؛ إن وُجد مسبقًا لا يُرسل شيء.
- حالات الطلب: المفتاح = حالة + رقم الطلب، ولا إرسال إذا حُفظت نفس الحالة دون تغيير.
- المستند البديل (فاتورة/سند جديد) له معرّف جديد فيُرسل له بريد جديد.

## 3. فشل البريد
- فشل Resend لا يلغي العملية ولا يظهر للعميل كفشل. يُسجَّل في السجل نفسه: «فشل» + سبب مختصر، بدون أسرار أو بيانات حساسة.

## 4. الأحداث
| الحدث | إلى |
|---|---|
| تسجيل عميل جديد (بعد إكمال البيانات، ليس عند OTP) | العميل + المسؤول |
| تقديم طلب (إعفاء/جدولة/إتاحة النسبة/أي نوع) | العميل + المسؤول |
| تحت الإجراء (under_review) / قيد التنفيذ (processing) | العميل |
| نقص مستندات (مع المستندات وملاحظة المسؤول إن سُجلت فقط) | العميل |
| رفع العميل للمستندات المطلوبة | المسؤول |
| إصدار عقد / سند / فاتورة (القيمة من سجل الفاتورة) | العميل |
| توقيع العقد / السند | المسؤول |
| الموافقة / الاكتمال / الرفض (السبب فقط إن وُجد تعليق) | العميل |
| تسجيل سداد الفاتورة | **لا يوجد إجراء سداد في النظام حاليًا** — سيُجهَّز القالب ولا يُربط، ويُذكر كبند يحتاج قرارك |

- أسماء أنواع الطلبات تظهر بالعربية (طلب إعفاء، طلب جدولة، إتاحة النسبة النظامية) بدل الاسم الداخلي.
- البريد الإداري الحالي لطلب جديد (بالمرفقات) يُستبدل بالقالب الموحد بدون مرفقات (روابط الملفات الخاصة لا تُرسل خارج البوابة). **يُرجى التأكيد إن رغبت بإبقاء المرفقات.**

## 5. القالب الموحد
- رأس بالشعار الرسمي الحالي، عنوان الحدث، جدول بيانات، زر إجراء، تذييل رسمي.
- ألوان #2A0E32 / #B99A55 / #FFFFFF / #FBFAF8، عربي RTL، متوافق مع الجوال.
- الأزرار تقود إلى rifanss.com (عرض الطلب، استكمال المستندات، توقيع العقد/السند، عرض الفاتورة) وتتطلب تسجيل الدخول؛ لا روابط مباشرة لمستندات خاصة.

## 6. الاختبار
- حساب عميل تجريبي على بريد اختبار، تنفيذ الدورة كاملة، التحقق من وصول كل رسالة مرة واحدة، إعادة الاستدعاء للتأكد من عدم التكرار، ومحاكاة فشل للتأكد من بقاء العملية.
- حذف بيانات الاختبار فقط، ثم تقرير بكل حدث ونتيجته.
