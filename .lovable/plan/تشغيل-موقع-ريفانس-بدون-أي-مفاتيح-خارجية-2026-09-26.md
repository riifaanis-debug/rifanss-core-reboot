# تشغيل موقع ريفانس بدون أي مفاتيح خارجية

## الوضع الحالي
- الموقع يُبنى بنجاح ويعمل على المعاينة (الرئيسية، الخدمات، الحاسبة، الدخول، اتصل بنا) بدون أخطاء في المتصفح.
- لم يُطلب أو يُدخل أي مفتاح. تم إلغاء نموذج طلب المفاتيح.

## ما سيتم
1. **التعامل الآمن مع غياب المفاتيح** في كل وظيفة خلفية تعتمد على خدمة خارجية، دون حذف أي كود:
   - البريد (إشعارات المدير، رمز التحقق، طلبات الإعفاء): إذا غاب مفتاح البريد تُسجَّل الرسالة وتُعاد نتيجة "تم التخطي" بدل الخطأ، فلا يتعطل إرسال الطلبات.
   - HubSpot: تخطٍ صامت للمزامنة عند غياب المفتاح.
   - PayPal: رسالة واضحة "الدفع الإلكتروني غير مفعّل حاليًا" بدل انهيار الصفحة.
   - دخول المدير: يعتمد على قاعدة البيانات (حساب المدير موجود) عند غياب مفاتيح المدير.
   - رمز التحقق بالجوال (OTP): يُحفظ الرمز في القاعدة ويُسجَّل؛ الإرسال الفعلي يُفعَّل لاحقًا بإضافة المفتاح.
2. **لا قيم وهمية ولا مفاتيح تجريبية**، ولا تغيير في التصميم أو المحتوى أو الهيكل.
3. **تحقق كامل**: بناء نظيف، فحص الصفحات الرئيسية ولوحة العميل والمدير (بعد الدخول)، وتجربة إرسال طلب للتأكد أنه يُحفظ رغم غياب البريد.
4. **تسليم قائمة منفصلة بالمفاتيح** المطلوبة فعليًا بعد نجاح التشغيل.

## قائمة المفاتيح المتوقعة (تُراجع وتُسلَّم بعد التشغيل)
| المفتاح | الخدمة | ما لن يعمل بدونه |
|---|---|---|
| RESEND_API_KEY | البريد | إشعارات المدير، إرسال رمز التحقق بالبريد، إرسال طلبات الإعفاء |
| ADMIN_EMAIL | البريد | عنوان استلام إشعارات المدير |
| HUBSPOT_API_KEY | HubSpot | مزامنة العملاء والصفقات |
| PAYPAL_CLIENT_ID / PAYPAL_CLIENT_SECRET | PayPal (حقيقي) | الدفع الإلكتروني للفواتير |
| PAYPAL_SANDBOX_CLIENT_ID / SECRET + PAYPAL_ENV | PayPal (تجريبي) | اختياري للاختبار فقط |
| ADMIN_USERNAME / ADMIN_PASSWORD / ADMIN_EMAIL_PASSWORD | دخول المدير البديل | اختياري؛ الدخول يعمل من القاعدة |
| WHATSAPP_* (4 مفاتيح) | واتساب | إرسال رمز التحقق عبر واتساب (غير مستخدم حاليًا في الكود المنقول) |

## تفاصيل تقنية
- تعديل مسارات `src/routes/api/public/fn/*` و`src/lib/rifans-mail.server.ts` لفحص وجود المتغير داخل المعالج وإعادة `{ success: true, skipped: true, reason }` بدل رمي خطأ.
- `paypal-order` يعيد 503 برسالة مفهومة؛ الواجهة الحالية تعرض الخطأ كما هي.
- لا تغيير في ملفات الواجهة.
